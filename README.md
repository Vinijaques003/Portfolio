# Portfólio Profissional

## Descrição
**Aluno:** Vinicius Jaques
Esse projeto é uma página pessoal com informações profissionais que apresenta meu perfil, meus projetos, minhas habilidades, tecnologias e minhas formas de contato.

## Tecnologias utilizadas
- HTML
- CSS
- Bootstrap 5.3.3

## Funcionamento do site
Ao acessar o site, você verá, na parte superior, o menu de navegação, que contém os links que levam às seções de Perfil, Projetos, Habilidades, Tecnologias e Ferramentas e Contato.

Em cada seção, há cartões que apresentam os conteúdos. Por exemplo, na seção Contato, existe o cartão "Fale Comigo", com duas opções: enviar e-mail e acessar o GitHub.

Ao clicar na opção de e-mail, o programa direciona o visitante para escrever um e-mail ao usuário. E ao clicar na opção GitHub, o visitante é direcionado ao perfil ou repositório do usuário no GitHub.

## Novo recurso implementado
Foi adicionado ao portfólio um efeito visual aos cartões, quando é passado o mouse sobre um deles, acontece uma pequena elevação no cartão, ele basicamente sobe um pouco e aparece uma sombra pequena, com uma transição suave.

Esse efeito foi desenvolvido utilizando CSS, por meio das propriedades `:hover`, `transform`, `box-shadow` e `transition`.
